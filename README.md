# Demo Portfolio

Open `index.html` in a browser to view the demo portfolio. It includes:

- Landing with parallax effect
- Top navigation linking to pages (Career, Portfolio, Articles, About)
- Career timeline with 6 dummy entries
- Articles section with internal navigation
- Portfolio page with sub-navigation and dummy projects
- About section with image, bio, and PDF resume download
- Contact info merged into About page (see About > Contact)

To run locally, simply open the file in your browser or use a simple static server, for example:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```
